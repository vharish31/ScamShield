Speaker1: হে, তুমি মোক শুনা?
Speaker2: নিশ্চিত, হ্যালো, কি হৈছে?
Speaker1: মই এটা ই-কমাৰ্চ প্লেটফৰ্মৰ গ্ৰাহক সেৱা প্ৰতিনিধি। আপোনাৰ একাউণ্টত কিছু পইণ্ট আছে যিসমূহ আজি ৰাতিপুৱা নিৰ্মীয়মান হ'ব। আপুনি সেইবোৰ ব্যৱহাৰ কৰিছেনে?
Speaker2: সঁচাকৈয়ে? মই লক্ষ্য কৰা নাছিলো।
Speaker1: হয়, এই পইন্টসমূহ পূৰ্বৰ ক্ৰয়ৰ পৰা পঠোৱা হৈছিল, ইয়াক কিছু নগদ ধন হ্ৰাস কৰিবলৈ ব্যৱহাৰ কৰিব পাৰি, যদি আপুনি ইয়াক ব্যৱহাৰ নকৰে, তেন্তে ই স্বয়ংক্ৰিয়ভাৱে শূন্য হ'ব।
Speaker2: মই এই পইণ্টবোৰ কেনেকৈ পৰীক্ষা কৰিম?
Speaker1: মই ইতিমধ্যে আপোনাক বিনিময়যোগ্য সামগ্ৰীসমূহৰ লিংক থকা এটা মেছেজ পঠিয়াইছো।
Speaker2: ঠিক আছে, মই লগে লগে গৈ চাওঁ।
Speaker1: যদি আপোনাৰ কোনো প্ৰশ্ন আছে তেন্তে যিকোনো সময়তে মোক যোগাযোগ কৰক।
Speaker2: আপোনাৰ সোঁৱৰাই দিয়াৰ বাবে ধন্যবাদ, ই সঁচাকৈয়ে বহুত সহায় কৰিছিল।
