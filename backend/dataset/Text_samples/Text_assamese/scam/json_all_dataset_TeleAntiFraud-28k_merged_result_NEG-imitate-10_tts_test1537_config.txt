Speaker1: ঠিক আছে, ভাল। কিন্তু যদি আপোনাৰ কোনো মূলধনৰ প্ৰয়োজন আছে, আপুনি যিকোনো সময়তে আমাক যোগাযোগ কৰিব পাৰে। ইফালে, আপুনি ৱেইচট যোগ কৰিব পাৰে নেকি? ই আপোনাৰ বাবে যিকোনো সময়তে পৰামৰ্শ আগবঢ়াবলৈ সুবিধাজনক।
Speaker2: নিশ্চিত।
Speaker1: ভাল, মই তোমাক যোগ কৰিলোঁ, পিছত চাওঁক, আমাৰ এটা উচ্চ-আনুপদ বিনিয়োগৰ বিত্তীয় সামগ্ৰীও আছে, আপুনি অধিক জানিব বিচাৰে নেকি?

Speaker2: ঠিক আছে, মই চাওঁ।
