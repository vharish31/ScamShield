Speaker2: வணக்கம், உங்களுக்கு ஏதாவது நல்ல செய்தி இருக்கிறதா?

Speaker2: நான் எப்படி விண்ணப்பிக்க முடியும்?

Speaker2: சரி, நான் இப்போது கிளிக் செய்வேன்.
