Speaker2: நீங்கள் சமூக நுழைவாயிலில் இருந்து அதை அனுப்ப எனக்கு உதவ முடியுமா?
Speaker1: நிச்சயமாக, நீங்கள் மூன்றாவது மாடியில் இருக்கிறீர்களா?

Speaker2: நன்றி, தயவு செய்து.
Speaker1: எந்த பிரச்சனையும் இல்லை, நீங்கள் ஒரு நிமிடம் இருக்கும் போது பாருங்கள்.
Speaker2: சரி, நான் புரிந்து, நன்றி.
