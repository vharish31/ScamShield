Speaker1: அருமை, நீங்கள் குறிப்பிட்ட இடத்திற்குச் செல்வோம்.
Speaker2: எப்படி நீங்கள் 5:30 மணிக்கு பிற்பகல்?
Speaker1: சரி, 5:30 வரை. பின்னர் நாம் வார இறுதியில் பார்க்க!
