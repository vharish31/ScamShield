Speaker1: வணக்கம், எப்படி இருக்கிறீர்கள்?
Speaker2: வணக்கம், நீங்கள் என்னை கேட்க முடியுமா?
Speaker1: நீங்கள் எங்கே இருக்கிறீர்கள்?
Speaker2: நீங்கள் சதுக்கத்தில் வந்து, கூட?
Speaker1: நீங்கள் நூலகம் நுழைவாயிலில் இங்கே வர முடியுமா?
Speaker2: சரி, நான் இப்போது போகிறேன், அது ஒரு சில நிமிடங்கள் எடுக்கும்.
Speaker1: சரி, நான் வாசலில் காத்திருக்கிறேன்.
Speaker2: ஹம்ம், சாலையில் பல கார்கள் இல்லை, நாம் விரைவில் வரும்.
Speaker1: உங்கள் பக்கத்தில் வானிலை எப்படி இருக்கிறது?
Speaker2: வானிலை நன்றாக இருக்கிறது, சற்று குளிர், நீங்கள் இன்னும் ஆடைகளை அணிய வேண்டும்.
