Speaker2: நீங்கள் அந்த கட்டிடம் எண் நான்கு எந்த மாடியில் உள்ளன?

Speaker2: சரி, உங்கள் வழியில் கவனமாக இருங்கள்.
Speaker1: கவலைப்பட வேண்டாம், நான் விரைவாக வந்தேன்.
