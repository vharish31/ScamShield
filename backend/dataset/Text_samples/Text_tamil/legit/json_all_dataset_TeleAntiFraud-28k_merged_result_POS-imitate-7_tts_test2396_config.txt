Speaker2: ஹே, நான் இப்போது நினைவில், நீங்கள் சினிமா சென்றார்?

Speaker1: சரி, சினிமா திரையரங்கு நுழைவாயிலில் சந்திப்போம்.
Speaker2: சரி, குறிப்பிட்ட நேரத்தில் திரையரங்கு நுழைவாயிலில் சந்திப்போம்.
Speaker1: சரி, சாலையில் பாதுகாப்பு கவனம் செலுத்துங்கள்.
Speaker2: நன்றி. சாலையில் சந்திப்போம்.
