Speaker1: வணக்கம், எப்படி இருக்கிறீர்கள்?
Speaker2: வணக்கம், நீங்கள் வந்துவிட்டீர்களா?
Speaker1: நான் மெட்ரோவிலிருந்து இறங்கினேன், நீ எங்கே?
Speaker2: நான் உங்களுக்காக இங்கே காத்திருக்கிறேன், மெட்ரோ நிலையத்தின் வெளியே இடது பக்கத்தில் உள்ள காபி ஷாப்பிற்கு வெளியே.
Speaker1: சரி, நான் அந்த கஃபே பார்க்க, நாம் அங்கு செல்ல இப்போது.
Speaker2: சரி, நான் இங்கே காத்திருக்கிறேன்.
Speaker1: சரி, இங்குள்ள எந்த நல்ல புத்தகக் கடைகளையும் நீங்கள் பார்க்க முடியுமா?
Speaker2: புத்தகக் கடை! இடதுபுறத்தில் ஒரு பெரிய புதிய சீன புத்தகக் கடை உள்ளது. புத்தகங்கள் அனைத்தும் அங்கே உள்ளன.
Speaker1: சரி, நன்றி, பின்னர் சந்திப்போம்.
Speaker2: ஹே, பின்னர் சந்திப்போம்.
