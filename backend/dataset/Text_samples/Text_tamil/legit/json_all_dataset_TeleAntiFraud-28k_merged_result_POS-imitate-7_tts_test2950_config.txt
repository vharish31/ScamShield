Speaker1: தயவுசெய்து நீங்கள் வரும்போது வர வேண்டிய அவசியம் இல்லாதவர்களின் பெயர்களை எங்களிடம் கூறுங்கள்.
Speaker2: சரி, நன்றி, பின்னர் சந்திப்போம்.
