Speaker2: உங்கள் வேலை நேரம் என்ன?

Speaker2: நான் இப்போது திரும்பி செல்ல முடியுமா?

Speaker2: சரி, நான் சுமார் பத்து நிமிடங்களில் அங்கு வருவேன், நன்றி.
Speaker1: சரி, நாங்கள் கடையில் நீங்கள் காத்திருக்க வேண்டும்.
