Speaker1: ஹே, எங்கே போகிறாய்?
Speaker2: நீ இன்னும் வெளியே வந்திருக்கிறாயா?
Speaker1: நீங்கள் கொண்டு வந்த விஷயங்கள் இன்னும் வீட்டில் உள்ளன?
Speaker2: இங்கே, அவர்கள் அனைவரும் நீங்கள் கொண்டு, வேகமாக கீழே இப்போது.
Speaker1: சரி, நான் உடனே போகிறேன்.
Speaker2: சரி, நான் இங்கே காத்திருக்கிறேன்.
Speaker1: நீங்கள் சமூகத்தின் கிழக்கு வாயில் பார்க்க முடியுமா?
Speaker2: நான் அதை பார்க்கிறேன், கிழக்கு வாயில் என் வலது கையில் உள்ளது.
Speaker1: நான் கிழக்கு வாயிலிலிருந்து புறப்பட்டு விரைவாக வந்தேன்.
Speaker2: சரி, நான் கிழக்கு வாயிலில் காத்திருக்கிறேன்.
