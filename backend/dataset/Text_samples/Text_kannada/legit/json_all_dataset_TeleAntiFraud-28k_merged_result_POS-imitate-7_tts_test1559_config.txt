Speaker2: ಹಾಯ್, ನೀವು ಹೇಗೆ? ಕೆಲಸದಲ್ಲಿ ಸಾಕಷ್ಟು ಕಾರ್ಯನಿರತವಾಗಿದೆ. ನೀವು ಹೇಗೆ?
Speaker1: ಹೌದು, ನಾನು ಇತ್ತೀಚೆಗೆ ಹೆಚ್ಚಿನ ಸಮಯ ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದೇನೆ. ಈ ವಾರಾಂತ್ಯದಲ್ಲಿ ನಿಮಗೆ ಯಾವುದೇ ಉಚಿತ ಸಮಯವಿದೆಯೇ? ಒಟ್ಟಿಗೆ ಊಟಕ್ಕೆ ಹೋಗೋಣ.

Speaker1: ನಂತರ ನೋಡೋಣ. ರಸ್ತೆಯಲ್ಲಿ ಜಾಗರೂಕರಾಗಿರಿ.
Speaker2: ಸರಿ, ಧನ್ಯವಾದಗಳು. ಈ ವಾರಾಂತ್ಯದಲ್ಲಿ ನೋಡೋಣ!
