Speaker1: ಸರಿ, ನಾನು ಶೀಘ್ರದಲ್ಲೇ ಅಲ್ಲಿಗೆ ಬರುತ್ತೇನೆ.
Speaker2: ಯಾವುದೇ ಸಮಸ್ಯೆ ಇಲ್ಲ, ನಾನು ನಿರ್ಗಮನದ ಅತ್ಯಂತ ಗೋಚರ ಸ್ಥಳದಲ್ಲಿ ನಿಂತಿದ್ದೇನೆ, ನೀವು ನನ್ನ ಕೈಯನ್ನು ಹಿಸುಕುತ್ತಿರುವುದನ್ನು ನೋಡುತ್ತೀರಿ ಮತ್ತು ಅದು ಅಷ್ಟೇ.
Speaker1: ನೀವು ಕಪ್ಪು ಸೂಟ್ ಧರಿಸುತ್ತೀರಾ?
Speaker2: ಹೌದು, ನಾನು. ನೀವು ನನಗೆ ಕರೆ ಮಾಡಲು ಬಂದಿದ್ದೀರಿ.
Speaker1: ಸರಿ, ಧನ್ಯವಾದಗಳು. ಸುಮಾರು ಹತ್ತು ನಿಮಿಷ ಎಡ ಅಥವಾ ಬಲಕ್ಕೆ.
Speaker2: ಯಾವುದೇ ಸಮಸ್ಯೆ ಇಲ್ಲ, ರಸ್ತೆಯಲ್ಲಿ ಜಾಗರೂಕರಾಗಿರಿ.
Speaker1: ನಾನು ಬಂದೆ, ನಿನ್ನನ್ನು ನೋಡಿದೆ.
Speaker2: ಅದ್ಭುತ, ನಾವು ಪಾರ್ಕಿಂಗ್ ಸ್ಥಳಕ್ಕೆ ಹೋಗಿ ಕಾರು ತೆರೆಯಲು.
