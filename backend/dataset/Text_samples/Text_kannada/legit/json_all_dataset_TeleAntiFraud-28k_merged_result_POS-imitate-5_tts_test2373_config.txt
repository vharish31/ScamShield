Speaker2: ಹಲೋ, ನೀವು ಯಾರು?
Speaker1: ಇತ್ತೀಚೆಗೆ ನೀವು ಹೇಗೆ ಇದ್ದೀರಿ?
Speaker2: ಹೇ, ಬಹಳ ಸಮಯದಿಂದ ನೋಡಿಲ್ಲ, ನೀವು ಹೇಗೆ?
Speaker1: ನೀವು ನಿಮ್ಮ ಹೊಸ ಕೆಲಸವನ್ನು ಪ್ರಾರಂಭಿಸಿದ್ದೀರಾ?
Speaker2: ಹೇ, ಕೆಟ್ಟದ್ದಲ್ಲ, ಕೇವಲ ಸ್ವಲ್ಪ ಕಾರ್ಯನಿರತ, ಮತ್ತು ನೀವು ಹೇಗೆ?
Speaker1: ಹೌದು, ಇತ್ತೀಚೆಗೆ ಹಳೆಯ ಕಂಪನಿಯಲ್ಲಿ ಸಾಕಷ್ಟು ಯೋಜನೆಗಳಿವೆ.
Speaker2: ಅದು ಅದ್ಭುತವಾಗಿದೆ, ನಮಗೆ ಸಮಯ ಸಿಕ್ಕಾಗ ನಾವು ಒಟ್ಟಿಗೆ ಕಾಲ ಕಳೆಯೋಣ.
Speaker1: ಹೇ, ನಿನ್ನ ವಾರಾಂತ್ಯ ಹೇಗಿತ್ತು?
Speaker2: ಈ ವಾರಾಂತ್ಯದಲ್ಲಿ ನಾವು ಭೇಟಿಯಾಗಲು ಹೇಗೆ?
Speaker1: ನಾವು ಹಳೆಯ ಸ್ಥಳದಲ್ಲಿ ಎರಡು ಗಂಟೆಗೆ ಭೇಟಿಯಾಗೋಣವೇ?
Speaker2: ಸರಿ, ನಂತರ ನೋಡೋಣ.
