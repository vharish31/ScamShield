Speaker2: ಹೇ, ನಾನು ಈಗ ಇಲ್ಲಿ, ನೀವು ಎಲ್ಲಿದ್ದೀರಿ?
Speaker1: ನಾನು ಮೆಟ್ರೋ ನಿಲ್ದಾಣದಿಂದ ಇಳಿದಿದ್ದೇನೆ, ರಸ್ತೆಯನ್ನು ದಾಟಲು ಸಿದ್ಧವಾಗಿದ್ದೇನೆ.
Speaker2: ಸರಿ, ಜಾಗರೂಕರಾಗಿರಿ, ರಸ್ತೆಯನ್ನು ದಾಟಿದ ನಂತರ ನೇರವಾಗಿ ಮುಂದೆ ನಡೆದು, ಮತ್ತು ಬಲಗಡೆಯಲ್ಲಿರುವ ಕಾಫಿ ಅಂಗಡಿಯನ್ನು ನೀವು ನೋಡುತ್ತೀರಾ ಎಂದು ನೋಡಿ?
Speaker1: ನಾನು ನಿಮ್ಮನ್ನು ನೋಡಿದೆ, ನಾನು ನಿಮ್ಮನ್ನು ಹುಡುಕಲು ಹೊರಟೆ.
Speaker2: ಸರಿ, ನಾನು ಕಾಫಿಶಾಪ್ ಬಾಗಿಲ ಬಳಿ ನಿಮಗಾಗಿ ಕಾಯುತ್ತಿದ್ದೇನೆ, ಬೇಗಬೇಗಬೇಡ, ಜಾಗರೂಕರಾಗಿರಿ.

Speaker2: ರಸ್ತೆಯಲ್ಲಿ ಜಾಗರೂಕರಾಗಿರಿ.
