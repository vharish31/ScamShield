Speaker2: ನಿಮ್ಮಲ್ಲಿ ಎಷ್ಟು ಮಂದಿ ಇದ್ದೀರಿ?

Speaker2: ಸರಿ, ನಾಲ್ಕು ಜನರ ಆಸನಗಳು ಸರಿ. ನೀವು ವಿಂಡೋ ಸೀಟ್ ನಂತಹ ವಿಶೇಷ ಆಸನಗಳ ಅಗತ್ಯವಿದೆಯೇ?

Speaker2: ಸರಿ, ವಿಂಡೋ ಸೀಟನ್ನು ನಿಮಗಾಗಿ ಕಾಯ್ದಿರಿಸಲಾಗಿದೆ. ನೀವು ಯಾವುದೇ ವಿಶೇಷ ಆಹಾರದ ಅವಶ್ಯಕತೆಗಳನ್ನು ಹೊಂದಿದ್ದೀರಾ, ಉದಾಹರಣೆಗೆ ಮಸಾಲೆ ಅಥವಾ ಸಮುದ್ರಾಹಾರವನ್ನು ತಿನ್ನುವುದಿಲ್ಲವೇ?
Speaker1: ನಾನು ಮಸಾಲೆ ತಿನ್ನುವುದಿಲ್ಲ, ಇತರರಿಗೆ ವಿಶೇಷ ಅವಶ್ಯಕತೆಗಳಿಲ್ಲ.
Speaker2: ಸರಿ, ನೀವು ಮಸಾಲೆ ತಿನ್ನುವುದಿಲ್ಲ, ನಾವು ವಿಶೇಷ ಗಮನ ಪಾವತಿ ಮಾಡುತ್ತದೆ. ನಾವು ಬೇರೆ ಏನು ಸಹಾಯ ಮಾಡಬಹುದು?
Speaker1: ಇನ್ನು ಇಲ್ಲ, ಧನ್ಯವಾದಗಳು.
