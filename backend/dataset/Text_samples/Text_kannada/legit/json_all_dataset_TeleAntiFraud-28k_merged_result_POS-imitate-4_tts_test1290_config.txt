Speaker1: ಹಲೋ, ನೀವು ಹೇಗೆ?
Speaker2: ಹಲೋ, ನಾನು ನಿಮಗೆ ಏನಾದರೂ ಸಹಾಯ ಮಾಡಬಹುದೇ?
Speaker1: ನಿಮ್ಮ ಫಿಟ್ನೆಸ್ ಪ್ರೋಗ್ರಾಂ ಬಗ್ಗೆ ಇನ್ನಷ್ಟು ಹೇಳಿ?
Speaker2: ಹೌದು, ನಮ್ಮ ವೈಯಕ್ತಿಕ ತರಬೇತುದಾರ ಸೇವೆಯು ಬಹಳ ಜನಪ್ರಿಯವಾಗಿದೆ, ಮತ್ತು ನಿಮ್ಮ ದೇಹದ ಸ್ಥಿತಿ ಮತ್ತು ಫಿಟ್ನೆಸ್ ಗುರಿಗಳ ಆಧಾರದ ಮೇಲೆ ನಾವು ವ್ಯಾಯಾಮ ಯೋಜನೆಯನ್ನು ಕಸ್ಟಮೈಸ್ ಮಾಡಬಹುದು.
Speaker1: ಅದು ಒಳ್ಳೆಯದಾಗಿದೆಯೇ? ಆಗ ನಾನು ಮುಂಚಿತವಾಗಿ ಕಾಯ್ದಿರಿಸಬೇಕೇ?
Speaker2: ಹೌದು, ನಾನು ನಿಮಗೆ ಉತ್ತಮ ಸೇವೆಯನ್ನು ಒದಗಿಸಬಲ್ಲೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಲು, ನೀವು ಮುಂಚಿತವಾಗಿ ಅಪಾಯಿಂಟ್ಮೆಂಟ್ ಮಾಡಿಕೊಳ್ಳುವಂತೆ ನಾನು ಶಿಫಾರಸು ಮಾಡುತ್ತೇನೆ. ನೀವು ನನಗೆ ಅನುಕೂಲಕರವಾದ ಸಮಯವನ್ನು ಹೇಳಬಹುದು, ಮತ್ತು ನಾನು ನಿಮಗಾಗಿ ಅದನ್ನು ವ್ಯವಸ್ಥೆ ಮಾಡುತ್ತೇನೆ.
Speaker1: ಸರಿ, ಮುಂದಿನ ವಾರ ಶುಕ್ರವಾರ ಸಂಜೆ 3 ಗಂಟೆಗೆ ನಾನು ಬರಬಹುದೇ?
Speaker2: ನಾನು ಶುಕ್ರವಾರ ಸಂಜೆ 3 ಗಂಟೆಗೆ ನಿಮಗಾಗಿ ಅಪಾಯಿಂಟ್ಮೆಂಟ್ ಮಾಡಬಹುದು. ದಯವಿಟ್ಟು ನಿಮ್ಮ ಕ್ರೀಡಾ ಸಲಕರಣೆಗಳನ್ನು ತರಲು ಮರೆಯದಿರಿ.
Speaker1: ಸರಿ, ನಿಮ್ಮ ಸಹಾಯಕ್ಕೆ ಧನ್ಯವಾದಗಳು.
Speaker2: ನಿಮ್ಮ ಆಗಮನವನ್ನು ನಾವು ಎದುರು ನೋಡುತ್ತಿದ್ದೇವೆ. ನೀವು ಯಾವುದೇ ಪ್ರಶ್ನೆಗಳನ್ನು ಹೊಂದಿದ್ದರೆ, ದಯವಿಟ್ಟು ಯಾವುದೇ ಸಮಯದಲ್ಲಿ ನಮ್ಮನ್ನು ಸಂಪರ್ಕಿಸಿ. ವಿದಾಯ!
