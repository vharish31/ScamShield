Speaker1: ಹೇ, ನೀವು ಮನೆಯಲ್ಲಿ?
Speaker2: ಏನಾಯ್ತು?
Speaker1: ನಾನು ಸೂಪರ್ಮಾರ್ಕೆಟ್ನಿಂದ ಬಂದಿದ್ದೇನೆ, ಕೆಲವು ಹಣ್ಣುಗಳನ್ನು ಖರೀದಿಸಿದೆ, ನಿಮಗಾಗಿ ಕೆಲವು ತಂದಿದ್ದೇನೆ.
Speaker2: ನಿಜಕ್ಕೂ? ಅದು ಅದ್ಭುತವಾಗಿದೆ. ಧನ್ಯವಾದಗಳು. ನೀವು ಎಲ್ಲಿ? ನಾನು ಅದನ್ನು ತಕ್ಷಣ ಪಡೆಯುತ್ತೇನೆ.
Speaker1: ನಾನು ಸಮುದಾಯ ಗೇಟ್ ನಲ್ಲಿ, ಕೆಳಗೆ ಬನ್ನಿ.
Speaker2: ಸರಿ, ನಾನು ತಕ್ಷಣ ಕೆಳಗೆ ಬರುತ್ತೇನೆ.
Speaker1: ನೀವು ಕೆಳಗೆ ಬಂದಾಗ, ನೀವು ಒಂದು ಕಸದ ಚೀಲವನ್ನು ತರಬಹುದು? ನಾವು ಅದನ್ನು ಮನೆಯಲ್ಲಿ ಬಳಸಿದ್ದೇವೆ.
Speaker2: ಸರಿ, ಹಾಗಿದ್ದರೆ ನೋಡೋಣ.
Speaker1: ನಾಳೆ ಒಂದು ಛತ್ರಿ ತರಲು ಮರೆಯದಿರಿ, ಹವಾಮಾನ ಮುನ್ಸೂಚನೆ ಮಳೆ ಮುನ್ಸೂಚನೆ.
Speaker2: ನನಗೆ ನೆನಪಿಸಿದ್ದಕ್ಕೆ ಧನ್ಯವಾದಗಳು.
