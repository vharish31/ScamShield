Speaker1: ಹೇ, ನಿಮ್ಮ ಕಡೆ ಸಿಗ್ನಲ್ ಹೇಗಿದೆ?
Speaker2: ಸಿಗ್ನಲ್ ಚೆನ್ನಾಗಿದೆ, ಮತ್ತು ನೀವು?
Speaker1: ಅದು ಪರವಾಗಿಲ್ಲ, ನಾನು ಇಲ್ಲಿ ಸ್ವಲ್ಪ ಶಬ್ದವನ್ನು ಹೊಂದಿದ್ದೇನೆ, ನೀವು ಏನು ಬಯಸುತ್ತೀರಿ?
Speaker2: ನೀವು ಸಾಮಾನ್ಯವಾಗಿ ಯಾವ ರೀತಿಯ ಟೇಕ್ಆ್ಯಟ್ ಅನ್ನು ಆದೇಶಿಸುತ್ತೀರಿ?
Speaker1: ನಾನು ಇತ್ತೀಚೆಗೆ ಆ ಸಣ್ಣ ರೆಸ್ಟೋರೆಂಟ್ಗೆ ಭೇಟಿ ನೀಡುತ್ತಿದ್ದೇನೆ. ರುಚಿ ಇನ್ನೂ ಉತ್ತಮವಾಗಿದೆ, ನೀವು ಹೇಗೆ?
Speaker2: ನಾನು ಕಳೆದ ಬಾರಿ ಆ ಸಣ್ಣ ರೆಸ್ಟೋರೆಂಟ್ನಲ್ಲಿ ಆದೇಶಿಸಿದೆ, ಅದು ಉತ್ತಮವಾಗಿತ್ತು, ಈ ಬಾರಿ ನಾನು ಅವರಿಂದ ಆದೇಶಿಸಲು ಬಯಸುತ್ತೇನೆ.
Speaker1: ನೀವು ನೇರವಾಗಿ ಅಪ್ಲಿಕೇಶನ್ನಿಂದ ಆನ್ಲೈನ್ನಲ್ಲಿ ಆದೇಶಿಸಬಹುದು, ಅವರ ಗೋಮಾಂಸ ಮತ್ತು ಹುರಿದ ಕೋಳಿ ಡ್ರಮ್ಸ್ಟಿಕ್ಗಳು ಬಹಳ ಜನಪ್ರಿಯವಾಗಿವೆ.
Speaker2: ಸರಿ, ನಾನು ಅಪ್ಲಿಕೇಶನ್ ತೆರೆಯುತ್ತೇನೆ ಮತ್ತು ನೋಡುತ್ತೇನೆ. ಸರಿ, ನೀವು ಕಳೆದ ಬಾರಿ ಹೇಳಿದ ಸಿಹಿ ಅಂಗಡಿ? ನಾನು ಅದನ್ನು ಪ್ರಯತ್ನಿಸಲು ಹೋಗಲು ಬಯಸುತ್ತೇನೆ.
Speaker1: ಸಿಹಿ ಮಧುಮೇಹದ ಅಂಗಡಿ, ಅದು ಆ ಜಾಹೀರಾತು ರಸ್ತೆಯ ಮೂರನೇ ಮಹಡಿಯಲ್ಲಿ, ಸಿಹಿ ಜೇನು ಸಮಯ ಎಂದು ಕರೆಯಲ್ಪಡುತ್ತದೆ, ನೀವು ಖಂಡಿತವಾಗಿಯೂ ಅದನ್ನು ಇಷ್ಟಪಡುತ್ತೀರಿ.
Speaker2: ಸರಿ, ಈ ವಾರಾಂತ್ಯದಲ್ಲಿ ನಾನು ಹೋಗುತ್ತೇನೆ, ಶಿಫಾರಸು ಮಾಡಿದ್ದಕ್ಕೆ ಧನ್ಯವಾದಗಳು.
