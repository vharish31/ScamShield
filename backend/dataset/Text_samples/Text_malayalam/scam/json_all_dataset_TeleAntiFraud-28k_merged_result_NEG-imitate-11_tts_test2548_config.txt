Speaker2: ഹലോ, എന്താ കിട്ടിയത്?

Speaker2: ഓ, ശരിക്കും, പിന്നെ നമ്മൾ ഇപ്പോൾ എന്തു ചെയ്യും?
Speaker1: നിങ്ങളുടെ അവകാശങ്ങൾ ഉറപ്പാക്കുന്നതിന്, ഞങ്ങളുടെ ഔദ്യോഗിക ആപ്പ് ഡൌൺലോഡ് ചെയ്ത് ആപ്പ് വഴി ഈ പ്രശ്നം കൈകാര്യം ചെയ്യണം.
Speaker2: എങ്ങനെ ഡൌൺലോഡ് ചെയ്യാം?
Speaker1: മൊബൈൽ അപ്ലിക്കേഷൻ സ്റ്റോർ തുറന്ന് "സ്പീഡി എക്സ്പ്രസ് ഔദ്യോഗിക പതിപ്പ്" എന്നതിനായി തിരയുക, അത് ഡൌൺലോഡ് ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യുക, തുടർന്ന് രജിസ്റ്റർ ചെയ്ത് ലോഗിൻ ചെയ്യുക. അതിനുശേഷം, അത് പ്രവർത്തിപ്പിക്കുന്നതിനുള്ള നിർദ്ദേശങ്ങൾ പാലിക്കുക.
Speaker2: എനിക്ക് എന്ത് വിവരങ്ങളാണ് നല് കേണ്ടത്?
Speaker1: ഐഡന്റിറ്റി പരിശോധനയ്ക്കായി ദയവായി നിങ്ങളുടെ പേര്, ഫോൺ നമ്പർ, ഐഡി നമ്പർ എന്നിവ നൽകുക.
Speaker2: ശരി, എനിക്ക് മനസ്സിലായി, നിങ്ങളുടെ സഹായത്തിന് നന്ദി.
